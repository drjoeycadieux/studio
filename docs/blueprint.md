# **App Name**: AuthNest

## Core Features:

- Login Interface: Implement a user login interface with fields for username/password and a submit button. This is a basic authentication form.
- Protected Page: Create a protected page that is only accessible after successful login. This page will display a welcome message and user information.
- Firebase Authentication: Integrate Firebase Authentication for handling user authentication. This will manage user accounts and session persistence.

## Style Guidelines:

- Primary color: Teal (#008080) for a clean and modern look.
- Secondary color: Light gray (#F0F0F0) for backgrounds and subtle contrasts.
- Accent: Orange (#FFA500) for interactive elements and calls to action.
- Clean and readable sans-serif fonts for all text elements.
- Use a simple, centered layout for the login form and protected page content.
- Subtle fade-in animations for page transitions and form elements.
